A Kanban-based framework that coordinates AI agents through a deterministic orchestrator, organized in three layers: board state, agent role contracts and the orchestrator loop. It uses only the Python standard library, a CLI handles Product Owner interactions, and key policies are verified with mock agents. (Private repo.)
